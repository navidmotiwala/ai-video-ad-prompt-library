# Advanced prompt combinations

[← Back to library](../README.md)

**Purpose:** Practical reference for advanced prompt combinations in AI video advertising.

## 1. Luxury macro

**How to use:** /macro-orbit + /low-key + /rim-light + /texture-pass.

**Example:** Perfume bottle with slow gold light sweep.

## 2. High-energy sports

**How to use:** /tracking + /low-angle + /speed-ramp + /impact.

**Example:** Running shoe on track.

## 3. Clean product demo

**How to use:** /locked-off + /high-key + /benefit-demo + /packshot.

**Example:** Home appliance in real use.

## 4. Tech assembly

**How to use:** /exploded-view + /magnetic-assembly + /edge-light.

**Example:** Headphone components join into finished product.

## 5. Lifestyle creator

**How to use:** /handheld + /pov + /room-tone + /benefit-demo.

**Example:** Creator demonstrates travel accessory.

## 6. Sensory food

**How to use:** /macro-100 + /slow-motion + /foley + /high-key.

**Example:** Coffee pouring into cup.

## Reusable prompt pattern

```text
Create a product advertisement for [EXACT PRODUCT] using luxury macro.
Scene: [SETTING]. Action: [ONE PHYSICAL ACTION]. Camera: [ONE MOVEMENT].
Lighting: [LIGHTING]. Duration: [SECONDS]. Aspect ratio: [RATIO].
Preserve product geometry, packaging and approved brand identity.
Use only verified product claims. Add text and logos in post-production.
```

**Production check:** Review the final video frame by frame for geometry, physics, continuity, claims and licensing.
