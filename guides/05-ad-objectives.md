# Ad objectives and formats

Choose the objective before selecting a creative style.

## 1. Awareness

**Goal:** Help new audiences notice and remember the product.

- **Pattern interrupt:** Start with an unusual visual or action.
- **Problem setup:** Show the situation the product addresses.
- **Product reveal:** Introduce the product clearly.
- **Brand memory:** Finish with a recognizable packshot.

## 2. Consideration

**Goal:** Help viewers evaluate the product.

- **Demonstration:** Show how it works.
- **Objection handling:** Address a common concern with evidence.
- **Comparison:** Use matching conditions and verified details.
- **Feature explanation:** Show one benefit at a time.
- **Use-case montage:** Show practical applications.
- **Testimonials:** Use genuine, permission-based customer feedback.

## 3. Conversion

**Goal:** Encourage a specific action.

- **Offer reveal:** Display an approved offer.
- **Verified price:** Use accurate current pricing.
- **Product close-up:** Reinforce what is being sold.
- **Call to action:** Give one clear next step.
- **Deadline:** Include only a real deadline.

## 4. Retention

**Goal:** Help existing customers continue using the product.

- **Onboarding tip:** Explain a useful first step.
- **Feature walkthrough:** Show how to use a feature.
- **Usage reminder:** Reinforce a helpful habit.
- **Cross-sell:** Introduce a relevant complementary product.

## 5. Advocacy

**Goal:** Encourage authentic recommendations.

- **Customer story:** Use genuine customer experiences.
- **Review montage:** Include approved, attributed reviews.
- **Creator collaboration:** Show a real collaboration.
- **Referral explainer:** Explain the actual referral offer.

## Common video formats

| Format | Typical use |
| --- | --- |
| **6-second bumper** | One idea and strong product recognition |
| **8-second visual hook** | Fast reveal or visual demonstration |
| **15-second short** | Hook, benefit and call to action |
| **30-second social ad** | Problem, demonstration, proof and CTA |
| **45-second demo** | More detailed product walkthrough |
| **60-second explainer** | Education or complex product features |
| **Silent retail display** | Visual-first, text added during editing |
| **Shoppable video** | Clear product demonstration and purchase context |
| **Marketplace listing** | Accurate product features and practical use |
| **Localized master** | Replace voice, text and offers for each market |
